# Validador de Números de WhatsApp

Este é um projeto para validação de números de WhatsApp usando `whatsapp-web.js` (Puppeteer), Express, Socket.io e HTML/CSS/JS simples para a interface do usuário.

## Como rodar localmente

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Execute o servidor:
   ```bash
   npm start
   ```

3. Abra `http://localhost:3000` no seu navegador.
